# Archived SAFOR release-candidate artifacts

The repository root intentionally contains only the current release candidate's release evidence, notes, checksums and versioned generic Framework.

Historical release-candidate evidence is retained here for auditability. These files are historical and must not be interpreted as the current release state.

Current release truth is defined by:
- `VERSION`
- `RELEASE-FACTS.json`
- `RELEASE-MANIFEST.json`
- the current `RELEASE-EVIDENCE-<VERSION>.json`
- the current `SHA256SUMS-<VERSION>.txt`
